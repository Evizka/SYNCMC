# Изменения MCSync

## 0.4.0 — 2026-10-03

### Cinematic-композиция по визуальному ориентиру
- Оригинальный локальный фон voxel-мира, крупное название сборки, узкая навигация слева и кнопка запуска-капсула. MISTY-код/логотип/чужие UI-ассеты не включены.
- Скругление всех QPushButton/QToolButton, специальных вариантов и стандартных Qt-кнопок диалогов. Навигация сохраняет доступные имена и подсказки.
- Видимые hover-блик/подсветка (260 мс), обратная связь нажатия и переходы страниц/сборок (360 мс). Геометрия/цель клика остаётся стабильной.
- Библиотека и поиск доступны при свёрнутой навигации; список/фильтры можно раскрыть и снова свернуть. Счётчики и настройки доступны клавиатурой.
- Панель пати прокручивается на небольших экранах, без наложения членов пати и кнопок.
- Настоящий Qt-GIF с демонстрацией движения. Pillow нужен только для инструмента захвата, не для приложения.

### Сборка и проверки
- Фон включён через PyInstaller --add-data; в архиве нет loader-shims или временных демо-JAR/миров.
- Дополнительные регрессии для локального ассета, капсул, промежуточных кадров hover/press, навигации, поиска и размера окон.
- Реальная сетевая проверка установки допускает один повтор при временном timeout/connection error стороннего сервера; assert/другие ошибки не скрываются.
- Включены доработки связи/приглашений из 0.3.1 ниже. Предварительная версия, без цифровой подписи.

## 0.3.1 — 2026-10-03

### Понятнее пати и интерфейс
- Причины сетевой ошибки различаются: таймаут, недоступный/занятый хост, отклонённое приглашение, конфликт сессии, повреждённый ответ или локальные настройки.
- Реальный обратный отсчёт до автоматической попытки и «Помощь со связью», без необходимости повторять проверку вручную.
- Явная смена приглашения сохраняет сборку/миры и last-sync revision: ни фоновый монитор, ни замена ссылки не меняют Minecraft/loader и не обходят подтверждение версии.
- В хост-приглашении свёрнуты папки/правила; секретная ссылка скрыта по умолчанию и показывается только явно.
- Повреждённый host_settings.json не ломает диалог; перед созданием новой пати сохраняется приватная копия оригинала.
- Интерактивные и клавиатурно доступные счётчики модов/миров; более понятные шаги первого запуска и заголовок «Мои сборки».

### Надёжность
- Медленный выход из недоступной комнаты вынесен из supervisor heartbeat; число leave-запросов ограничено двумя. Остальные присутствия истекают по TTL.
- Старый ответ от сменённой ссылки и ответ до последней синхронизации не возвращают ложный онлайн/индикатор обновления.
- Будущая сохранённая дата синхронизации не подавляет реальную связь; некорректное значение уменьшения анимаций проверяется по типу.
- Неожиданные исключения мониторинга показывают безопасный статус с переподключением вместо молчаливого исчезновения проверок.
- Дополнительные core/HTTP/Qt регрессии для ошибок, обратного отсчёта, настроек, приватности, смены приглашения и навигации.

Предварительная версия; пользовательские аккаунты/GPU/произвольные модпаки по-прежнему проверяются на реальном ПК. Для пати нужны открытый MCSync у хоста и LAN/VPN-доступ.

## 0.3.0 — 2026-10-02

### Пати и связь без ручных проверок
- Сохранённое приглашение автоматически восстанавливает соединение при открытии MCSync. Heartbeat каждые 10 секунд, переподключение с задержкой 5/10/20/30 секунд; проверки не останавливаются во время установки и игры.
- Настоящий список участников: хост, друзья, «Вы», «В лаунчере», «Обновляется», «В игре» и состояние последней синхронизации. Нет декоративных онлайн-счётчиков: при обрыве список скрывается, устаревший успешный ответ не остаётся зелёным.
- Присутствие хранится только в памяти хоста и истекает через 45 секунд без heartbeat. Для нового клиента требуется одно сохранённое приглашение, не повторное подключение каждый вечер.
- Восстановление собственной пати после перезапуска с тем же портом и секретной ссылкой — по включённой опции. Явное «Остановить» отключает автовосстановление. Старые раздачи без этой опции не включаются молча.
- Имя для друзей задаётся отдельно: аккаунт Minecraft, IP, пути и токены не передаются в список. Стабильные идентификаторы привязаны к комнате; приватная сессия защищает чужой участник от подмены/выхода.
- Старый хост 0.2.0 остаётся совместим: проверка связи/ревизии автоматическая, но список пати появится после его обновления.

### Понятнее интерфейс
- Aurora переработана: нейтральные тёмные слои, лавандовая основная кнопка, пиксельный ночной пейзаж и меньше одинаковых рамок.
- Постоянная панель пати справа остаётся видна в модах, мирах и консоли; статистика объединена в одну спокойную полосу, заметки не вытесняются списком друзей.
- Фильтры и сортировка сворачиваются в боковой панели, но сохраняют поиск и выбранные значения.
- Плавное появление страниц (180 мс) и hover (140 мс), без перемещения цели кнопки. «Уменьшить анимации» сохраняется в настройках и останавливает текущий переход.
- Aurora сохранена основной темой. Более компактная шапка, одна основная кнопка «Играть», приглашение для хоста и подсказка следующего шага.
- Пати видна на сводке: аватары с инициалами, цвет реальной связи, ответ в мс, явное переподключение. Статистика, запуск и заметки отделены от сетевых настроек.
- Кнопка «Обновить сейчас» появляется только при изменениях; проверять соединение вручную больше не нужно. Ручное обновление остаётся в «Ещё».
- Повторная вставка той же ссылки открывает уже существующую сборку, не создаёт дубликат.
- Смена версии с подтверждением, бэкап миров, приватные черновики и автоматические обновления перед запуском сохранены.

### Надёжность и релизы
- Протокол пати ограничивает размеры запросов/ответов и число участников; отклоняет подменённую сессию, некорректный JSON/HTML-имена и browser-origin POST. Он не позволяет загружать, удалять или менять файлы хоста.
- Неизменённые моды не хешируются заново на каждом heartbeat; перед отдачей файла его хеш всё равно проверяется.
- Регрессии для реального HTTP, двух клиентов, рестарта, TTL, приватности, совместимости и Qt-сценариев. Только 2D/offscreen локально; настоящие Qt-библиотеки и frozen startup проверяются нативной матрицей CI. GPU/игровой процесс на ПК пользователя не считаются проверенными.
- Прямые native ZIP Windows/Linux/macOS и SHA-256 со страницы Releases, без обёртки Actions. Предварительная версия, без цифровой подписи.

## 0.2.0 — 2026-10-02

### Интерфейс
- Forest, Nord и Ember добавлены к Graphite/Aurora/Paper. Aurora выбрана основной для новой установки; сохранённая тема не сбрасывается.
- Отдельная библиотека карточек, комфортный и компактный режимы, избранное и сортировка по недавнему запуску.
- Обзор с реальными счётчиками модов/миров, временем игры, готовностью установки, заметками и состоянием синхронизации.
- Редактор параметров отдельно от сводки; длинные имена не растягивают окно.
- Приватный черновик переживает переключение, поиск и перезапуск. Версии/настройки применяются только по «Сохранить»; подтверждение и бэкап сохранены.
- Поиск в файлах, сохранение выделения при фоновых проверках, страницы Modrinth и корректная доступность кнопки установки.
- Горячие клавиши и диагностика через F1; новые скриншоты настоящего Qt-интерфейса.

### Надёжность
- Повреждённая сборка изолируется, а не ломает всю библиотеку. Повреждённые настройки/аккаунты сохраняются в приватном recovery перед перезаписью.
- Проверка типов профилей/метаданных, конечности/диапазона времени, формата Client ID и адресов серверов.
- Повреждённый installed marker переустанавливается безопасно; кеш манифеста проверяется по типу.
- Одновременное открытие одной папки данных двумя лаунчерами предотвращается QLockFile.
- Несколько файлов переключаются через FileTransaction: конфликт не оставляет наполовину изменённый набор.
- Потоковый бэкап миров с прогрессом/отменой; локальная смена версии не замораживает GUI при сжатии большого мира.
- Ограничение больших строк, ротация launcher.log и остановка дерева процессов. На Windows javaw заменяется соседним java.exe с CREATE_NO_WINDOW для захвата вывода.
- Отчёт диагностики не включает токены, имена аккаунтов, sync-ссылки и команды; пути и названия сборок остаются и требуют проверки перед отправкой.

### Проверки и сборка
- Дополнительные регрессии для черновиков, режимов, повреждённых данных, бэкапов, журналов, Modrinth и атомарного переключения.
- Нативные Windows/Linux/macOS ZIP, проверка source/frozen GUI и API загрузчиков.
- Отдельная сетевая Windows-проверка установки Minecraft 1.21.1 / Mojang Java / всех пяти загрузчиков. Не запускает игру и не использует аккаунт Microsoft.
- Minecraft-файлы, личные данные и локальные Qt-stubs не включаются в архивы.

Это предварительная версия: Microsoft-вход с одобренным Client ID, GPU и произвольные модпаки необходимо проверять на реальном ПК. Всегда сохраняйте отдельные копии важных миров.
