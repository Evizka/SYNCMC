# Original launcher artwork

`aurora-world.jpg` is an AI-generated, original voxel landscape commissioned for MCSync's
cinematic desktop interface. It is not a screenshot of the user's game, a third-party
launcher asset, or the attached MISTY reference. No logos or interface from that reference
are included. The asset is bundled locally by PyInstaller: no runtime image download.

The native Qt controls, account state, pack statistics and party presence are drawn separately
by the application. Screenshots use explicitly temporary demo data; production does not
inject fake online users or worlds.
