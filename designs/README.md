# Варианты оформления

1. **[Graphite](graphite.png)** — графит / зелёный (пока основной).
2. **[Aurora](aurora.png)** — фиолетовый / лаванда.
3. **[Paper](paper.png)** — светлый / синий.

[Сравнение](options.png). Это не концепт-арт: все изображения получены из настоящего
`MainWindow` / PySide6. Три темы доступны в **Настройки → Оформление**, без перезапуска
и без сброса несохранённых полей сборки. Параметры запуска отделены от версии/состава
сборки, расширенные команды свёрнуты, удаление и экспорт убраны в меню «Ещё».

На скриншотах временные демонстрационные данные. Сеть выключена; демонстрационные
JAR-файлы — заглушки только для визуализации списка, их нет в архиве приложения.
Индикатор «Автосинхронизация» означает подписку по ссылке, а не подтверждённую
доступность хоста. Индикатор обновления появляется только после сравнения ревизий.

Повторить захват в окружении с рабочим Qt:

```bash
QT_QPA_PLATFORM=offscreen python scripts/preview_designs.py --output designs
```

Для временного просмотра другой темы без изменения settings.json:

```bash
python mcsync.py --theme paper
```
