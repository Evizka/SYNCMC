# Оформление MCSync 0.4.1

## Новый экран и заметные анимации

[Главный экран 0.4.1](aurora.png) — цельный фон, большой заголовок, две кнопки и никаких
панелей статистики/заметок под баннером. [Управление сборкой](management.png) сохранено отдельно.
[GIF](motion.gif) показывает hover, press, переходы страниц и появление заголовка.

[Главный экран](aurora.png) — статичный UI-снимок 0.4.1. В приложении фон теперь выбирается
по активной теме: отдельные voxel-сцены Forest, Nord, Ember, Graphite, Aurora и Paper
описаны в [каталоге ассетов](../assets/README.md). Изображения локальные, не являются
реальными снимками игры и не используют чужие логотипы или код.

Вкладки управления имеют тематические векторные иконки и плавный fade при переключении.
Иконки нарисованы средствами Qt, без emoji и сторонних шрифтов.
**[GIF настоящего движения](motion.gif):** плавный hover-блик, нажатие и переходы страниц.
Это запись PySide6-виджетов, не концепт/веб-макет. Все данные в записи временные,
сеть отключена. Скриншоты сами по себе не показывают анимации.

Повторить GIF (только инструменту нужен Pillow):

```bash
python -m pip install pillow
QT_QPA_PLATFORM=offscreen python scripts/preview_motion.py --output designs/motion.gif
```

## Шесть тем

[Общее сравнение](options.png):

1. **[Forest](forest.png)** — лесной / шалфей. Здесь показана библиотека карточек.
2. **[Nord](nord.png)** — северный / ледяной. Здесь — компактный список модов.
3. **[Ember](ember.png)** — угольный / медный. Здесь — комфортный обзор сборки.
4. **[Graphite](graphite.png)** — графит / зелёный.
5. **[Aurora](aurora.png)** — фиолетовый / лаванда. Выбранная основная тема.
6. **[Paper](paper.png)** — светлый / синий. Здесь — параметры.

Это **реальный интерфейс MainWindow / PySide6**, не концепт и не веб-имитация. Все темы
переключаются в **Настройки → Оформление**, без перезапуска и без сброса полей.
Прежняя сохранённая тема пользователя остаётся на месте.

## Три компоновки

Обновлённая Aurora: нейтральные слои вместо фиолетовых рамок, ночной пейзаж, цельная полоса
статистики, сворачиваемые фильтры и постоянная пати справа. Скриншоты показывают установившееся
состояние; в приложении есть hover и переходы страниц. Уменьшение анимаций — в настройках.

[Сравнение компоновок](layouts.png) в выбранной теме Aurora:

- [Карточки](layout-gallery.png): отдельная стартовая библиотека; поиск, группы и избранное.
- [Комфортный обзор](layout-comfortable.png): реальные моды, миры, время, синхронизация и готовность к запуску.
- [Компактный](layout-compact.png): более низкая шапка, плотные строки сборок и файлов.

Тема и компоновка независимы: любую можно сочетать с любой. Режим выбирается через
**Настройки → Интерфейс**. В карточки можно перейти кнопкой **«Все сборки» / Ctrl+L**.
[Параметры](parameters.png) отделены от сводки, команды свёрнуты, удаление и экспорт
находятся в «Ещё». Несохранённые изменения восстанавливаются из приватного черновика.

## Пати без постоянных проверок

В 0.4.1 добавлены безопасные объяснения ошибки, реальный отсчёт до переподключения,
помощь со связью и смена приглашения без потери миров. Настройки раздачи свёрнуты,
ссылка скрыта до явного показа, счётчики модов/миров доступны с клавиатуры.

- [Ваша пати](aurora.png): участники в постоянной правой панели, ваше имя, роль хоста, статусы и время ответа.
- [Хост](party-host.png): одно постоянное приглашение и понятные кнопки для друзей.
- [Переподключение](party-reconnecting.png): нет ложного зелёного онлайна; сохранённая ссылка используется автоматически.

## Что именно на снимках

На скриншотах **временные демонстрационные данные**. Это демонстрационные участники/статусы, не реальные друзья пользователя. В production они приходят только от HTTP-хоста. Внешняя сеть выключена; JAR-файлы и мир —
заглушки только для визуализации счётчиков/списка, их нет в архиве приложения. В настоящей
сборке считаются её реальные файлы и время игры. В демонстрации пати используются синтетические имена и состояния;
сама сохранённая подписка не означает доступность хоста; недоступность показывается после реальной проверки.
Индикатор обновления появляется только после сравнения ревизий.

Мини-пейзажи карточек и иконки рисуются средствами Qt; основной shader-voxel-арт — отдельный
оригинальный локальный ассет. Чужие логотипы, код и скриншоты не включены. UX-ориентиры:
библиотека/управление сборками в
[3](https://prismlauncher.org/) и интерфейс библиотек Modrinth в
[2](https://nodecraft.com/support/games/minecraft/mods/how-to-use-the-modrinth-launcher).

Повторить захват в окружении с рабочим Qt:

```bash
QT_QPA_PLATFORM=offscreen python scripts/preview_designs.py --output designs
```

Временный просмотр без сохранения выбора:

```bash
python mcsync.py --theme nord --layout compact
```
