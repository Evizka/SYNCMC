# MCSync — быстрый старт

## Запустить лаунчер

1. Скачайте ZIP для своей ОС из GitHub Actions → Artifacts (или GitHub Release).
2. Если скачали Actions artifact, сначала извлеките из него вложенный `MCSync-windows-x64.zip` (или ZIP своей ОС). Затем **распакуйте нативный архив целиком**, не только EXE. У GitHub Release дополнительной ZIP-обёртки нет.
3. Windows: откройте `MCSync/MCSync.exe`. Linux: `MCSync/MCSync`. macOS: `MCSync.app`.
4. В «Аккаунты / скины» добавьте офлайн-ник или Microsoft-аккаунт. Для Microsoft предварительно нужен собственный одобренный Client ID в настройках. Пароль вводится только на сайте Microsoft.

Python для готового архива не нужен. Java и игра скачиваются при первом запуске Minecraft. Сборка не подписана; предупреждение SmartScreen/Gatekeeper само по себе не подтверждает ни безопасность, ни опасность файла — проверяйте источник и SHA-256.

## Хост

1. «Новая сборка» → Minecraft и Vanilla/Fabric/Quilt/Forge/NeoForge.
2. В «Обзоре» можно обновить версии, выбрать RAM и сохранить. Добавьте свои моды, ресурсы и конфиги в папку сборки.
3. «Раздать сборку» → свой LAN/VPN IP, порт 25589, нужные папки → «Запустить раздачу».
4. Скопируйте секретную ссылку и отправьте друзьям приватно. Лаунчер оставьте открытым. Окно раздачи можно закрыть.
5. Меняйте файлы у себя; новые версии Minecraft/загрузчика выбирайте в «Обзоре» и сохраняйте. Друзья получат обновление перед запуском.

Через интернет используйте VPN/оверлей либо настройте сетевой доступ/брандмауэр. Порт синхронизации и порт Minecraft-сервера различаются; автоматического обхода NAT нет.

## Друг

1. «Подключиться по ссылке» → ссылка хоста → подтвердите доверие модам.
2. Дождитесь первой установки, выберите аккаунт → «Запустить».
3. При смене версии появится окно изменений. Оставьте бэкап миров включённым; при понижении версии особенно осторожно обращайтесь с мирами.
4. При отмене версии игра не запускается и сборка не меняется. Кнопка «Синхронизировать» повторяет проверку отдельно от запуска.
5. Если хост выключен, можно запустить последнюю уже установленную сборку; кеш не содержит недостающих модов.

Рекомендуемый режим — «Спрашивать только при смене версий». «Автоматически» меняет версии без диалога, но с бэкапом миров.

## Важно

- HTTP не зашифрован; ссылка даёт доступ к файлам. Не публикуйте ссылку и проверьте `config` на секреты.
- Моды — исполняемый код. Подключайтесь только к доверенному хосту.
- Аккаунты/токены хранятся локально без шифрования. Не отправляйте папку данных друзьям.
- У подписки Minecraft/загрузчиком/модами управляет хост; свои RAM, Java, окно и заметки доступны.
- «Копия» создаёт независимую сборку. «Отсоединить» прекращает обновления, оставляя файлы.
- «Удалить сборку» удаляет её миры **и локальные бэкапы**. Сначала экспортируйте важные данные наружу.
- Офлайн-ник не авторизуется на online-mode серверах. Локальный PNG скина — только предпросмотр.

Подробности, исходный запуск и диагностика: `README.md`. Ошибки лаунчера — в `mcsync.log` (папка данных открывается из настроек); ошибки игры — «Консоль»/«Логи».
