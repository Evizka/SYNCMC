# 🌿 Cenote Swamp — Биом «Затопленные сеноты»

NeoForge 1.21.1 мод, добавляющий новый биом с глубокими карстовыми провалами,
гигантскими древними деревьями и туманной болотной атмосферой.

## 🌊 Что добавляет

### Биом: Затопленные сеноты (cenote_swamp)
- **Глубокие сеноты** — карстовые провалы 20-50 блоков глубиной, заполненные водой
- **Подводные пещеры** — расширяющиеся камеры на дне сенот с глиной и галькой
- **Светящийся мох** — освещает стенки сенот мягким зелёным светом
- **Мангровые корни** — свисают над входами в сеноты
- **Гигантские деревья** — массивные стволы 3-5 блоков шириной, воздушные корни, густые кроны
- **Лианы и мшистые основания**
- **Тёмная болотная вода** (зеленовато-чёрная)
- **Тяжёлый туман** — ограниченная видимость
- **Аксолотли** — обитатели глубин сенот
- **Слизни, лягушки, тропические рыбы** в подводных камерах

### Блоки
| Блок | Описание |
|------|----------|
| `peat` | Торфяной грунт — основа биома |
| `dark_peat` | Тёмный торф |
| `cenote_moss` | Светящийся мох (уровень света 5) |
| `mangrove_roots_block` | Блок корней |
| `muddy_stone` | Грязевой камень для стенок сенот |

## 📦 Сборка

```bash
# Установить JDK 21 (если нет)
sdk install java 21.0.3-tem

# Собрать мод
./gradlew build

# Запустить клиент с модом
./gradlew runClient

# Запустить data-gen
./gradlew runData
```

Артефакт: `build/libs/cenoteswamp-1.0.0.jar`

## 🗺️ Как найти биом

Биом генерируется в:
- Болотных биомах (заменяет часть свампов)
- Команда: `/locate biome cenoteswamp:cenote_swamp`
- Или создай новый мир и ищи тёмные участки с глубокими ямами

## 🎮 Как играть

1. Установи NeoForge 1.21.1+
2. Закинь `.jar` в папку `mods/`
3. Создай мир — биом появится автоматически
4. Или: `/locate biome cenoteswamp:cenote_swamp` → телепортируйся

## 🔧 Кастомизация

### Частота сенот
В `cenote_swamp_cenote.json` → `placement.rarity_filter.chance`:
- `10` = часто, `25` = редко, по умолчанию `18`

### Размер сенот
В `cenote_swamp_cenote.json` → `config`:
- `min_depth` / `max_depth` — глубина
- `min_radius` / `max_radius` — ширина входа
- `water_ratio` — % заполненности водой

### Деревья
В `cenote_swamp_giant_tree.json`:
- `canopy_radius` — размер кроны (10 = огромная)
- `branch_count` — количество ветвей
- `min_height` / `max_height` — высота

## ⚠️ Известные особенности

- Сеноты могут пересекать пещеры — это создаёт интересные комбинации
- Гигантские деревья могут генерироваться слишком близко друг к другу
- Вода в сенотах обычная Minecraft (не кастомная жидкость)
